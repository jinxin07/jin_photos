# Portfolio Website

A clean, responsive photography portfolio built with Next.js and Tailwind CSS.

## Getting Started

Follow these steps to set up and run the project locally.

### 1. Install Dependencies

Install the required packages listed in the `package.json` file:

```bash
npm install
```


### 2. Run the Development Server
Start the local development server to test and preview your site:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the application.
